## 一、启动与登录

- [ ] 冷启动 → 启动页 → 登录页；用 `20230101/123456` 登录 → 进主页
- [ ] 杀 App 再启动 → 直接进主页（token 持久化，不再要求登录）
- [ ] 错密码 `1234567` → toast「学号或密码不正确」
- [ ] 设置页退出登录 → 回登录页；桌面卡片回落「志愿者 / --」

## 二、首页

- [ ] 聚合数字与后端一致（今日时长/累计/积分/信用分）
- [ ] 本周推荐卡 + 活动流 6 条，点卡片进详情
- [ ] 搜索框输入中文关键词（如「义诊」）→ 列表过滤
- [ ] 「求助大厅」入口 → 切到互助 Tab

## 三、志愿大厅 / 活动详情

- [ ] 列表分类筛选、时间排序正常
- [ ] **详情页发布者卡有姓名/学院/信用分**（今天修的字段契约，重点确认）
- [ ] 挑一个未报名的活动点「立即报名」→ 变「扫码签到」；重复报名 → 后端文案
- [ ] 详情页「联系」→ **直接进与发布者的聊天页**（不再是复制提示）
- [ ] 聊天页发一条消息 → 气泡右下「未读」；用副号（苏晴）打开该会话 → 回到主号 2 秒内变「**已读**」

## 四、扫码签到（F1）

- [ ] 真机：签到页点「扫一扫」或右上角相机 → 系统扫码页拉起
- [ ] 对准签到二维码（内容 = 6 位数字，可用草料二维码生成 `336914`）→ **自动核销** → 绿色成功页（本次时长/累计/签到时间）
- [ ] 手输兜底：点「手输签到码」输 `250817` → 核销成功
- [ ] 错码 → toast「签到码不正确」；重复签 → toast「该活动已签到」

## 五、发布活动

- [ ] 发布表单：填标题/分类/时间/地点/人数/时长 → 发布成功
- [ ] 志愿大厅列表能看到新发布的活动

## 六、互助闭环（双设备演示核心）

- [ ] 主号发布求助（如「帮忙带一份晚饭」）→ 扣积分
- [ ] 副号接单 → 主号收到通知角标；主号详情页「完成」→ 副号积分入账
- [ ] 双方互评 → 信用分变动；重复评价被拦
- [ ] pending 求助（如 202 借吉他）详情页点「联系」→ toast「接单后方可与发布者沟通」

## 七、消息中心

- [ ] 顶部「志愿小鸿 · AI 助手」卡 → 点它 → **自动返回主页并切到小鸿 Tab**
- [ ] 「互助沟通」卡 → 会话列表（求助会话 + 活动会话混排，含未读徽章）
- [ ] 四类通知会话：最新一条预览 + 时间 + 未读数；点进分类列表；「全部已读」清零
- [ ] 发聊天消息 → 对方「互助动态」收到通知

## 十一、桌面卡片（F3）

- [ ] 长按桌面 → 添加「鸿志愿 2×4」→ 显示「Hi, 姓名 / 今日·累计时长 / 进行中·待签到 / 下一场」
- [ ] 点卡片 → 进 App
- [ ] 签到后再进一次首页 → 卡片数字刷新

## 已知边界（演示时主动说明，不算缺陷）

1. 证书数据为端侧生成（后端证书接口未建），保存/分享是真实能力
2. IM 为 2 秒轮询（演示无感差）；离线消息拉取后已读
3. 桌面卡片数据是「上次进 App 的快照」，30 分钟定时刷新或进首页即更新
4. 二维码内容约定为 6 位签到码，其他内容会提示改手输
